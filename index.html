01ゲーム概要

「或陽の大逆転サイコロ」は、大・逆・転・或陽という4種類の特殊なサイコロを使うチンチロ風のサイコロゲームです。2人はもちろん、複数人でも遊べます。盤上には大・逆・転の3個が共有サイコロとして置かれており、参加者が順番に同じ3個を振ります。或陽サイコロは、特殊な処理が必要になった時だけ使用します。

基本はチンチロ風の出目勝負ですが、特殊な出目が絡むと「反転」「交換」「総入れ替え」といった大逆転が起こりうるのがこのゲームの最大の特徴です。

02サイコロの種類と準備

すべて6面体で、特殊面以外は2〜6の数字が入っています。

サイコロ面の構成
大大 / 2 / 3 / 4 / 5 / 6
逆逆 / 2 / 3 / 4 / 5 / 6
転転 / 2 / 3 / 4 / 5 / 6
或陽或陽マーク / 2 / 3 / 4 / 5 / 6

用意するのは各1個、合計4個。大・逆・転の3個は参加者全員で共有して順番に振るサイコロで、普段は卓の真ん中に置いておきます。或陽サイコロは、特殊な処理が必要になった時にだけ振ります。

03ゲームの流れ

  1. 先攻が、盤上の大・逆・転の3個を振る。
  2. 出目を確定し、先攻側に記録する。
  3. 後攻が同じ3個を振る。
  4. 出目を確定し、後攻側に記録する。
  5. 両者の出目が揃った時点で、必要な特殊処理を行い、最終的な勝敗を判定する。

04出目の決め方

早見フローチャート ― 3個振った後、上から順にチェック
Q1. 3つとも同じ数字(ゾロ目)か？
YES → ピンゾロ(6章)
NO → Q2へ
↓
Q2. 234／345／456の連続3数字か？
YES → 階段(6章)
NO → Q3へ
↓
Q3. 同じ数字が2つ＋残り1つ、という組み合わせか？
YES → Q4へ
NO → Q5へ
↓
Q4. 残りの1つは数字か、特殊面(大/逆/転)か？
数字 → 通常出目(6章)
特殊面 → 特殊出目(7〜9章、効果発動)
↓
Q5. 特殊面(大/逆/転)が2つ＋数字1つ、という組み合わせか？
YES → その数字がそのまま出目(効果なし)
NO → 目無し(5章)

基本形

同じ数字が2つ、異なる数字が1つ出た場合、異なる方の数字が「出目」になります。

例：2・2・6 → 出目6 ／ 5・5・3 → 出目3

特殊面が1つ含まれる場合

同じ数字2つ＋特殊面1つの場合、その特殊面が「出目」として確定し、効果が発動します。

例：2・2・大 → 出目「大」／ 5・5・逆 → 出目「逆」

特殊面が2つ含まれる場合

特殊面2つ＋数字1つの場合は、数字の方がそのまま通常出目として扱われます。特殊効果は発動しません。

例：大・逆・6 → 出目6(効果なし)

特殊面は「出目」として確定した場合にのみ効果を発動します。盤面に出ているだけでは何も起こりません。

05目無しと振り直し

ピンゾロ・階段・通常出目のいずれにも当てはまらない場合、「目無し」になります。

各プレイヤーの最初の3個振りに限り、目無しが出た場合はチンチロと同様に振り直しが可能です。最初の1投を含めて合計3回まで振ることができ、役が出た時点でその出目を確定とします。3回とも目無しだった場合は、そのまま目無しとして扱われます。

※この振り直しルールは各プレイヤーの最初の3個振りのみに適用され、「転」による4個振り直し(9章)には適用されません。

06役の強さ

ピンゾロ ＞ 階段 ＞ 通常出目 ＞ 目無し

ピンゾロ

666 ＞ 555 ＞ 444 ＞ 333 ＞ 222 ＞ 111

通常の3個振りでは111は出ません。111は「転」の4個振り(9章)で、或陽を1として選んだ場合にのみ成立します。

階段

456 ＞ 345 ＞ 234

通常出目

出目6 ＞ 出目5 ＞ 出目4 ＞ 出目3 ＞ 出目2

同点になった場合のタイブレーク

同じ数字の出目同士が同点になった場合、揃った方(ペア)の数字が大きい方が勝ちます。

例：「2・2・3」(出目3、ペア2) と「4・4・3」(出目3、ペア4) → ペア4の方が勝利

特殊面2つ＋数字1つの形(4章参照)は数字のペアを持ちませんが、同じ数字の「同じ数字2つ＋異なる数字1つ」型と同点になった場合は、特殊面2つ＋数字1つの型の方が強いものとして扱います。特殊面2つ＋数字1つの型同士が同点になった場合は、比較できる情報が無いため引き分けとなります。

07特殊効果「大」

大 が出目になった場合に発動します。

① 数値決定大を出した本人が或陽サイコロを振る。出た数字が大の数値(或陽マークは1)。
② 効果数字の強さが反転：2＞3＞4＞5＞6(ゲーム終了まで継続)
③ 例外相手が目無しなら或陽を振らずそのまま大側の勝ち。階段・ピンゾロには勝てない。

数値の決定

大側本人が或陽サイコロを振り、出た数字を大の数値とします(或陽マークは1として扱う)。

効果：強さの反転

通常の数字の強さを反転させます。

通常：6 ＞ 5 ＞ 4 ＞ 3 ＞ 2

大が有効な状態：2 ＞ 3 ＞ 4 ＞ 5 ＞ 6

相手が目無しの場合は、或陽ロールを行わずそのまま大側の勝利です。階段・ピンゾロは大より強く、通常通りの強さ順が適用されます。大の効果は、そのゲームの最終的な勝敗判定まで継続します。

08特殊効果「逆」

逆 が出目になった場合に発動します。

① 数値決定逆を出した本人が或陽サイコロを振る。出た数字が逆側の「確定値」(或陽マークは1)。
② 効果確定値と、相手の元の出目の数字を交換する。交換後の2つの数字で勝敗を判定。
③ 例A＝逆(確定値6)、B＝出目2 → 交換後 A＝2／B＝6 → Bの勝ち
④ 特殊な強さ順相手が階段/ピンゾロ：役の強さが逆転し、或陽サイで数字(2〜6)が出れば逆側の勝ち。相手が目無し：数字が出ると目無し側の勝ち。或陽マークは不利になる側の救済(階段/ピンゾロ相手は相手の勝ち、目無し相手は逆側の勝ち)。

数値の決定

逆を出した本人が或陽サイコロを振り、その結果を逆側の「確定値」とします(或陽マークは1として扱う)。

効果：交換

確定値が決まったら、逆側の確定値と、相手が元々持っていた出目の数字を交換します。交換後の2つの数値で最終的な勝敗を判定します。

例：A＝逆(確定値6)、B＝出目2 → 交換後 A＝2、B＝6 → B勝利

相手が目無し・階段・ピンゾロの場合

逆は役の強さを逆転させます。逆側の確定値と相手の役を交換し、交換後の役で勝敗を決めます。

相手が階段・ピンゾロ或陽サイコロで数字(2〜6)が出れば逆側の勝ち(階段・ピンゾロが最弱になるため)。
相手が目無し或陽サイコロで数字(2〜6)が出ると目無し側の勝ち(目無しが最強になるため)。
或陽マークが出た時逆転で不利になる側への救済措置。階段・ピンゾロ相手なら相手側の勝ち、目無し相手なら逆側の勝ち。

目無し・階段・ピンゾロを出した側は、相手が逆を出した時点で勝敗が決まってしまうため、或陽マークはその救済として用意されています。

09特殊効果「転」

転 が出目になった場合に発動します。

① 基本処理両者とも4個全部(大・逆・転・或陽)を振り直す。大/逆/転の面は1として扱い、或陽マークは1〜6の好きな数字として扱ってよい。
② 3つ選ぶ振った4個から3個を選んで役を作る(或陽マークを1にして他の強制1と重ね、111ピンゾロにすることも可)。役が作れるのに目無しを選ぶ場合は要確認。役が全く作れない時のみ自動的に目無し。
③ 転×階段/ピンゾロ相手(階段/ピンゾロ側)が「そのまま保持」か「両者とも4個振り直し」かを選べる。
④ 転×目無し選択権なく、両者とも4個振り直しへ。

基本処理

両プレイヤーが4個すべてのサイコロ(大・逆・転・或陽)を使って振り直します。

出た面扱い
大 / 逆 / 転1として扱う
或陽マーク1〜6の好きな数字としてプレイヤーが選択可能

4個から3個を選ぶ

振られた4つのサイコロから3つをタップして選び、できる出目を確定します。或陽マークを1として選べば、他の強制1と重なって「111ピンゾロ」を作ることも可能です。4つの中に役を作れる組み合わせがあるのに目無しになる選び方をした場合は確認が入り、役が全く作れない場合は自動的に目無しとなります。4個振りの中で大・逆・転が出ても、それぞれの特殊効果は発動しません。

転×階段・ピンゾロ

相手が階段・ピンゾロの場合、その相手に「そのまま保持」か「両者とも4個振りへ移行」かの選択権があります。転×目無しの場合は選択権なく、両者とも4個振りへ移行します。

10大逆転 / 大逆転或陽

大逆転

通常の3個振りで、共有の大・逆・転サイコロがそれぞれ自分自身の特殊面を出した場合(自分の手番で、大が「大」、逆が「逆」、転が「転」を同時に出す)、大逆転が成立します。通常の役判定は行わず、その時点でそのプレイヤーがゲームを獲得します。進行は先攻→後攻の順のため、先攻が大逆転を成立させた場合、後攻は振らずに即時決着します。

大逆転或陽

「転」の4個振りで、大・逆・転・或陽の4つすべてが、それぞれ自分自身の特殊面を出した場合、大逆転或陽が成立します。通常の役判定を行わず、その時点でそのセットを獲得します。両者が同時に大逆転或陽を成立させた場合は、4個を振り直します。

11複合特殊処理

組み合わせ処理の要点
大+大 ／ 逆+逆 互いに或陽を振り、大きい方が勝ち。強さ順：或陽マーク＞6＞5＞4＞3＞2。
転+転 通常の転ルールをそのまま適用(両者4個振り直し)。
大+逆 先攻→後攻の順で各自或陽を振る。大側の数値と逆側の確定値を交換。大の反転効果は交換後も継続し、反転ランキングで比較。同数なら引き分け。
大+転 ／ 逆+転 転を優先。大・逆の効果は発動せず、両者そのまま4個振り直しへ。

大 + 大 ／ 逆 + 逆

両者が同じ特殊出目を出した場合、互いに或陽サイコロを振り、大きい方が勝ちます。強さ順：或陽マーク ＞ 6 ＞ 5 ＞ 4 ＞ 3 ＞ 2。

転 + 転

通常の転ルール(両者4個振り直し)をそのまま適用します。

大 + 逆

処理順は先攻→後攻。大側が或陽を振って数値を確定し、逆側も或陽を振って確定値を決めた後、大側の数値と逆側の確定値を交換します。大の反転効果は交換後も継続するため、最終的には交換後の数値を反転ランキングで比較します。同数の場合は引き分けです。

大 + 転 ／ 逆 + 転

転を優先します。大・逆の特殊効果は発動せず、そのまま両者4個振りへ移行します。

12引き分け

最終結果が完全に同じでタイブレークも適用できない場合、そのゲームは引き分けとして流れます。スコアは変化せず、次のゲームへ進みます。

13先攻・後攻

マッチ開始時は両者が或陽サイコロを振り、大きい方(或陽マークが最強)が先攻・後攻を選べます。同点の場合は振り直します。セット内ではゲームごとに先攻を交代し、セット終了後の次セット1ゲーム目は、前セットの敗者が先攻になります。

14セット・マッチ

  • セット：6ゲーム先取で獲得。5-5になった場合は2ゲーム差がつくまで継続。
  • マッチ：3セットマッチ。2セット先取でマッチ勝利。
  • 大逆転或陽が発生した場合、現在のゲームカウントに関係なく、そのプレイヤーがセットを獲得します。

15ポイントを賭けるモード

役の強さだけを競う通常モードに加えて、持ち点を賭け合う「ポイントを賭けるモード」も選べます。

基本ルール

  • 両者とも持ち点10,000ptからスタート。
  • 或陽ロールの対決で親・子を決定し、勝った方が親か子かを選ぶ。
  • 毎ゲーム、子が賭け金(100〜2,000pt、100pt単位、自分の持ち点が上限)を設定する。
  • 親→子の順で3個を振り、通常モードと同じ流れで勝敗を判定する。
  • 勝者は、成立した役の倍率ぶん賭け金を受け取る。負けた側が目無しであっても、倍率は変わらずそのまま適用される。

配当倍率

成立した役倍率
大逆転或陽×10
大逆転×7
ピンゾロ×5
出目「大」「逆」×3
階段×2
通常出目×1

「転」で振り直した場合は、最終的に確定した役の倍率が適用されます(転そのものに固有の倍率はありません)。

賭け金×倍率の計算や、複数人で遊ぶ際のポイントの受け渡しには、お手持ちのスマートフォンの電卓アプリなどを使うと手早く正確に計算できます。

試合構成

1セット6ゲーム×2セット、合計12ゲームを行い、終了時点で持ち点が多い方が勝者です。引き分けはポイントが動かず、ゲーム数のカウントにも含まれません。

賭け金の上限(100〜2,000pt)や試合構成(6ゲーム×2セット)は現在調整中の数値です。プレイ感に応じて今後変更される場合があります。

16更新履歴

v1.0
初版。4種のサイコロ・基本役・各特殊効果・セット/マッチ制を定義。
v1.1
通常出目の同点タイブレーク(ペア判定)ルールを追加。「逆」の或陽ロールを「大」と同じく本人が振る進行に統一。大逆転どうしの同時成立による振り直しルールを廃止し、先攻が成立させた時点で即時決着する仕様に変更。特殊面2つ＋数字1つ型と通常のペア型が同点になった場合、特殊面2つ型を優先する裁定を追加。
v1.2
各プレイヤー最初の3個振りに限り、目無し時にチンチロ式の振り直し(最大3回)を行えるルールを追加。持ち点を賭け合う「ポイントを賭けるモード」を新設(配当倍率・賭け金ルール・試合構成を含む)。

※ご利用にあたっての注意

「ポイントを賭けるモード」は、換金性のないポイントのやり取りによって対戦を盛り上げるための遊び方であり、現金・金銭、またはこれに相当する財産上の利益を賭けて遊ぶことを想定したものではありません。

現金や金銭的価値のある物品を賭けて本ゲームを行うことは賭博にあたり、法律により禁止されています。実際にプレイされる際は、金銭や財産上の利益を賭けることのないよう、ポイントや点数チップなど換金性のない手段の範囲でお楽しみください。
